# Cook Game Multiplayer

A co-op multiplayer cooking game built in Unity where players work together to prepare recipes and serve customers before time runs out.

---

## About

Cook Game Multiplayer is a real-time cooperative cooking game inspired by titles like *Overcooked!*. Players join a shared kitchen, receive recipe orders, and must coordinate to chop ingredients, cook dishes, and serve customers — all under a ticking clock.

The game emphasizes teamwork and communication, with each player taking on different roles in the kitchen to keep orders flowing efficiently.

---

## Gameplay

Players are given recipe orders that must be completed within a time limit. Each recipe requires a series of steps — gathering ingredients, preparing them at the right stations, and plating the final dish. The more orders completed correctly, the higher the score.

Coordination is key: two players trying to grab the same ingredient or blocking each other at a station can mean the difference between a perfect run and a failed order.

---

## Tech Stack

- **Unity** — Game engine
- **Unity Netcode for GameObjects** — Multiplayer networking
- **Unity Transport (UTP)** — Network transport layer
- **C#** — Primary scripting language
- **ShaderLab / HLSL** — Custom shaders and visual effects
